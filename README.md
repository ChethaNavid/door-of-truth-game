# Door of Truth

## Project Overview
Door of Truth is an action puzzle platformer developed using Unity. The game challenges players to answer multiple-choice questions under time pressure by selecting the correct door while navigating a collapsing environment.

---

## Genre
Action Puzzle Platformer

---

## Platform
PC (Windows)

---

## Story
The player is placed in a trial where each challenge tests their ability to identify the correct answer. Progression is only possible by choosing the door that represents the truth.

---

## Setting
The game takes place high up in the sky on floating platforms. The environment features a sunset sky with dark purple and warm tones, creating a calm and mysterious atmosphere.

---

## Gameplay Mechanics
- A question is displayed on a signboard.
- Three doors appear, each representing a multiple-choice answer.
- The doors move toward the player over time.
- Floating tiles drop one by one, forcing the player to keep moving.
- Choosing the correct door allows the player to progress.
- Choosing the wrong door causes the player to be pushed or fall.

---

## Controls
- Move: WASD or Arrow Keys
- Camera: Mouse
- Select Door: Move into the door

---

## Win and Lose Conditions

### Win Condition
- Successfully answer all questions and reach the final stage.

### Lose Conditions
- Selecting an incorrect door.
- Falling off the platform due to collapsing tiles.
- Being pushed off by an approaching door.

---

## Art Direction

- Floating platforms and large door assets
- Sunset sky with dark purple color palette
- Smooth and readable animations using Unity Animator

## How to Run the Game
1. Download and extract the full build folder.
2. Ensure the following files remain in the same directory:
   - DoorOfTruth.exe
   - DoorOfTruth_Data folder
   - UnityPlayer.dll
3. Run DoorOfTruth.exe.
